## Custom Web Applications

Customer portals, internal tools, dashboards and SaaS products. We build the
front end in React or Next.js and the backend in Python or Node.js on
PostgreSQL. Every build includes authentication, role-based access, an
automated test suite and a CI/CD pipeline. Typical projects run from six weeks
for a focused internal tool to several months for a multi-tenant platform.

## Mobile Applications

Cross-platform iOS and Android apps in React Native or Flutter, including
App Store and Play Store submission. We handle offline behaviour, push
notifications, in-app payments and analytics. Where an app needs deep platform
integration we write native modules rather than working around the framework.

## E-commerce

Storefronts on Shopify and WooCommerce, and bespoke headless commerce where an
off-the-shelf platform gets in the way. Work covers theme and template
development, payment and shipping integration, inventory and ERP sync,
multi-currency, subscriptions, and performance work on large catalogues.

## AI and Chatbot Integration

Retrieval-augmented assistants grounded in your own documentation, document
intelligence pipelines, and workflow automation that calls your existing
systems. We build the evaluation set alongside the assistant, so quality is
measured rather than assumed, and we design an explicit human handoff for
anything the assistant should not answer on its own.

## UI/UX Design

User research, information architecture, wireframes, high-fidelity design and a
reusable component library delivered in Figma. Design and engineering run in the
same team, so what is designed is what ships.

## Cloud and DevOps

Cloud architecture on AWS, GCP and Azure; infrastructure described in Terraform;
CI/CD pipelines; containerisation and Kubernetes; monitoring and alerting; and
migrations from on-premise or from another provider. We hand over the
infrastructure code, so nothing about your platform stays locked in our heads.

## Maintenance and Support

Monthly retainers covering uptime monitoring, security patching, dependency
upgrades, bug fixes and a pool of enhancement hours. Available for systems we
built and, after a short audit, for systems we did not.
