## 1. Scoping call

A free 45-minute conversation about the problem, who it affects, what already
exists and when it needs to be live. No preparation required.

## 2. Proposal

Within about three working days you get a written proposal: scope broken into
deliverables, a dated timeline, the team we would assign, and a fixed price.

## 3. Discovery

The first one to two weeks of the engagement. We map user journeys, agree the
technical approach, and produce a backlog neither side can misread later. For
design-led work this is where wireframes appear.

## 4. Build

Two-week iterations. Each ends with a working demo on a staging environment, not
a slide deck. You have direct access to the team in a shared channel throughout,
and a written progress summary lands every week.

## 5. Launch

Deployment, monitoring and alerting, a handover session, and documentation for
both the code and the infrastructure. We stay close through the first weeks in
production.

## 6. Support

A warranty period is included with every project. After it, most clients move
onto a monthly retainer for monitoring, patching and continued improvement.

## Quality practices

Automated tests on every project, code review on every change, CI/CD from the
first week rather than the last, and infrastructure described in code so an
environment can be rebuilt from scratch.
